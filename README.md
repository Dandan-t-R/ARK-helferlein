# ARK-Helferlein

Ein einfacher, frei nutzbarer **ARK: Survival Ascended‑Helfer‑Bot**, der mit Tipps und Informationen zur Seite steht.

---

## 🔧 Funktionen
- Durchsucht automatisch bekannte ARK‑Quellen:
  - CurseForge (Mods)
  - Dododex (Taming, Stats)
  - ArkCodes (Admin‑Befehle)
  - Steam Workshop (Community‑Guides)
  - Ark Wiki & Wikily (Allgemeine Infos)
- Antwortet im Discord‑Channel auf Stichworte wie **rex**, **taming**, **breeding**, **commands** usw.
- Gibt kurze Textausschnitte mit Quellenlink zurück.

---
